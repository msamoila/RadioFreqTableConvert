Radio Frequency Table Converter

This console application is receiving a comma separated values file (`.CSV`) with a list of radio channels in a format used by [RT Systems Software](https://www.rtsystemsinc.com/).

This Web page https://vectorradio.ca/ops/frequency-list/ contains a link to a [shared drive](https://drive.google.com/drive/folders/1-xVM_OY9Chow_VtwJ3bcwg8r6LtHV2NW) which has such `.CSV` file (RT-Systems_20260317.csv)

This application will convert the RT Systems file to a `.CSV` file accepted for import by the [TIDRADIO programming software](https://tidradio.com/pages/programming-software), for TD-H9 radio model.
